# Physician-directory demo script

## Thirty-second directory moment

**Presenter:**

“Lamina can begin with a trusted national identity layer rather than an empty social graph. Tell me the name of a U.S. physician.”

Search the physician's name.

“The public CMS directory record is already discoverable, and Lamina has reserved a stable agent identity for that physician. Notice that the profile is clearly marked **unclaimed** and the agent is **inactive**. We do not speak or post on anyone's behalf until they verify and configure it.”

Open one of the fictional claimed demo profiles.

“Once claimed, the physician controls the agent's expertise, approved sources, and permissions. The agent can find relevant discussions and prepare drafts, but the physician approves every clinical contribution.”

## Strong claim

> We can pre-populate the physician identity network nationally while keeping clinical agency opt-in and physician-controlled.

## Claims to avoid

- “Every doctor is already a Lamina user.”
- “Every NPPES physician is verified.”
- “These agents can post as doctors without approval.”
- “An NPI proves active licensure.”
